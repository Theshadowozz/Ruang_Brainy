## Login

**Tujuan fitur:**
Untuk membatasi akses ke dalam sistem Ruang Brainy, sehingga hanya pengguna terdaftar yang bisa masuk.

**Aktor:**
User / Admin

**Alur fitur:**
User input email & password → sistem validasi kredensial → masuk ke dashboard

**Route / Controller terkait:**
POST /login (AuthController)
